# Principios UX

> "Software empresarial muy potente que parece simple."
>
> "Mostrar solamente lo necesario para tomar la siguiente decisión o ejecutar la siguiente acción."
>
> "Complejidad por debajo, simpleza por arriba."

## Reglas
1. Less is more: cada elemento se justifica o se va.
2. No dashboards salvo necesidad real. No mosaicos de módulos. No sidebar global.
3. Máximo dos niveles principales de navegación visibles.
4. Progressive disclosure: primario visible, secundario compacto, terciario expandible. Excepción: un problema crítico se muestra aunque su sección esté plegada.
5. Edición contextual: se edita donde vive el dato, no en otra pantalla.
6. Paneles redimensionables y contraíbles cuando hay lista + detalle.
7. Una acción primaria por contexto; las secundarias, discretas.
8. NULL nunca se inventa como 0: "sin cargar", "sin asignar", "sin registrar", "sin plan", "sin línea base".
9. Mantener contexto: no sacar al usuario del Gantt para ver el detalle.
10. Evitar navegación innecesaria; el estado vive en la URL y es compartible.
11. Reutilizar patrones antes de crear nuevos: si existe una tabla, un tab, un drawer o un lenguaje de estados, ese es el que se usa.
12. Densidad profesional con scroll; nunca reducir la tipografía para meter más.
13. Un dato tiene una sola definición: si dos pantallas lo muestran, leen la misma fuente.
