# Referencias de UX (patrones, nunca visual ni color)

La identidad visual es SIEMPRE Echegaray. De cada plataforma se toma sólo el patrón:

- **Figma** — workspace profesional, split arrastrable, paneles contraíbles, propiedades laterales, interacción contextual.
- **Linear** — minimalismo, densidad con jerarquía, pocos bordes, selección sutil, reducción de ruido, sensación de velocidad.
- **Asana** — varias vistas del mismo trabajo (Gantt / Lista / Tablero / Próximos), filtros, navegación agregado ↔ detalle.
- **Jira** — jerarquía Obra → Rubro → Actividad → Tarea, responsables, estados, dependencias, bloqueos, historial.
- **Autodesk Construction Cloud** — lógica operativa de construcción: planificación, ejecución, avance, campo, impedimentos, equipos, documentación. Su profundidad, no su complejidad visual.
- **HubSpot** — ficha de entidad: identidad, propiedades, actividad, relaciones, documentos, acciones.
- **Notion** — progressive disclosure, información plegable, profundidad bajo demanda.
- **Google Calendar** — interacción temporal, hoy, escalas simples.
- **Stripe** — números, tablas limpias, estados, detalle progresivo (Economía).
- **JPMorgan / Treasury** — información financiera orientada a decisión: situación → riesgo → acción (Economía).

Prioridad por contexto: workspaces de obra → Figma, Linear, ACC, Asana, Jira, Notion. CRM/entidades → HubSpot, Linear, Notion, Figma. Economía → Stripe, Treasury, Linear, Google Calendar.
