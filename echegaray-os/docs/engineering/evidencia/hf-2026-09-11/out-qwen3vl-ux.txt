### **(1) Problemas de accesibilidad visibles**

**Hallazgo 1: Contraste insuficiente en texto de estado**
- **Dónde:** En la columna "ÚLT. MOV." (último movimiento), en las celdas que contienen el texto "sin movimientos".
- **Problema:** El texto "sin movimientos" está en gris muy claro (código hex: #A0A0A0) sobre fondo blanco. El contraste es inferior a 3:1, lo que no cumple con el requisito WCAG 2.2 AA para texto no importante.
- **Cambio:** Cambiar el color del texto a un gris oscuro (por ejemplo, #606060) o negro (#000) para alcanzar un contraste mínimo de 4.5:1.

**Hallazgo 2: Foco visual ausente en elementos interactivos**
- **Dónde:** En los botones de acción dentro de cada fila de cliente (por ejemplo, el icono de flecha hacia arriba junto a "OP 5156 · 08/09").
- **Problema:** No hay un indicador de foco visible (como un borde o sombra) cuando se navega por el tabulador. Esto hace imposible para usuarios que no usan ratón saber qué elemento está seleccionado.
- **Cambio:** Añadir un estilo de foco (por ejemplo, `outline: 2px solid #007BFF;`) a todos los elementos interactivos (links, botones, inputs) para que sean claramente identificables mediante teclado.

**Hallazgo 3: Etiquetas de columnas no asociadas al contenido**
- **Dónde:** Las etiquetas de las columnas ("OBRAS", "CONTRATADO", etc.) son solo texto plano en la parte superior de la tabla.
- **Problema:** No están correctamente asociadas a sus respectivas columnas mediante atributos `scope` o `aria-labelledby`, lo que dificulta su comprensión para lectores de pantalla.
- **Cambio:** Añadir `scope="col"` a las etiquetas de las cabeceras de columna (`<th>`) y asegurar que cada celda de datos (`<td>`) esté correctamente vinculada a su cabecera correspondiente mediante `aria-describedby` si es necesario.

### **(2) Problemas de UX**

**Hallazgo 4: Densidad excesiva y falta de separación visual**
- **Dónde:** En la fila de cliente "Messina", donde se muestra una lista de obras con múltiples campos (OP, fecha, monto) en una sola celda.
- **Problema:** La información está densamente apilada sin suficiente espacio vertical o visualización de jerarquía. Es difícil distinguir rápidamente entre diferentes obras o datos dentro de una misma celda.
- **Cambio:** Reducir la densidad aplicando más espaciado vertical entre filas y considerar desglosar esta celda en múltiples líneas o usar una estructura de tarjeta para cada obra individual.

**Hallazgo 5: Columna "MARGEN" mal interpretada por el usuario**
- **Dónde:** En la columna "MARGEN", donde se muestran valores como "$ 88.885.620 57 %".

- **Cambio:** Separar el valor monetario y el porcentaje en dos columnas distintas, o usar una única columna con un formato claro como "Margen: $88.885.620 (57%)". Establecer un formato consistente para todas las columnas de dinero.
